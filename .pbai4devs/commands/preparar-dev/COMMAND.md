# Preparar desenvolvimento

Entrada: objetivo ou erro observado, se houver. Pré-requisito: projeto existente.

Comece pelo [diagnóstico](../diagnosticar/COMMAND.md), ou reutilize o inventário
se ele ainda representar o ambiente. Passe o resultado para
[preparar-dev](../../skills/projeto/preparar-dev/SKILL.md). Reúna dúvidas antes
de alterações e use os scripts e ferramentas indicados pela skill.

Saída: ambiente verificado, comandos de execução, URL e pendências; evidências
locais em `.agent-tests/`. Não reinicie o planejamento de produto.
