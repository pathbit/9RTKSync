# git-branch

Confira branch atual, worktrees e alterações locais. Crie ou troque a branch
solicitada preservando as alterações locais. Quando a operação pertencer a
uma spec, siga [implementar-spec](../../specs/implementar-spec/SKILL.md)
e escolha a base conforme o fluxo do projeto.
