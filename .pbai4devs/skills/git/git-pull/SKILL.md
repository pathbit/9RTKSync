# git-pull

Siga `.pbai4devs/rules/git/RULE.md`. Confira branch, upstream, alterações locais
e divergência; busque e integre o remoto sem descartar trabalho ou reescrever
histórico. Se for necessário um commit de merge, confira antes as identidades
efetivas. Se houver conflito, preserve o estado e resolva-o somente dentro do
escopo autorizado.

Para integrar uma implementação revisada, siga
[git-merge](../git-merge/SKILL.md) com as provas do commit de origem.

Confira o resultado de cada consulta e informe limitações. Por exemplo, um
ignore global inacessível pode afetar a listagem de arquivos não rastreados.
